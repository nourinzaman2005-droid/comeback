# ComeBack promo and demo video script

**Total length:** 2 minutes 56 seconds (hard limit 3:00).
**Format:** 1920 x 1080, 30 fps, MP4 under 40 MB.
**Voice:** one narrator from the team, warm and unhurried. Read at a natural pace (about 150 words a minute). Every line below has been timed to fit.
**Rendered edit:** the `video/` folder builds this exact cut in Remotion, with Screen Studio style zooms, cursor focus and speed ramps. Drop your recorded voiceover in as `video/public/voiceover.mp3` and re-render (see "How to produce it" at the end).

## The story in one breath

Talented women have lost their cricket careers after having a baby, not because they stopped being good, but because nobody gave them a plan. The ICC has now written that plan, but only as a PDF. We are an all-women team, and we turned it into ComeBack: a phone app that guides a mother back to cricket step by step, with her own clinician approving every stage.

## Final narration (as recorded)

The finished videos use an AI voiceover: Microsoft's Ava neural voice (`en-US-AvaMultilingualNeural`). Some lines were tightened to fit the scenes, so the exact spoken text and timing live in `video/scripts/voiceover.py`. Run `python scripts/voiceover.py` from `video/` to regenerate `public/voiceover.mp3` and `public/voiceover-with-music.mp3`, then re-mux the music version onto the videos. Names are spelled phonetically ("Noo-rin", "Aash-ra") so the voice pronounces them correctly.

## How to produce it

The finished silent cut is already rendered at `video/out/comeback-promo.mp4` (1920 x 1080, 2:56). You only need to add the voice.

1. **Record the voiceover.** Read the voiceover column above in a quiet room on a phone, one take per scene, following the timings. Join the takes into one MP3 and save it as `video/public/voiceover.mp3`.
2. **Render with voice.** From the `video/` folder run `npm run render:voice`. Optionally add soft background music in any editor afterwards.
3. **Optional: re-record the walkthrough.** With the app running locally (`npm start` in the project root), run `npm run record`, then `node scripts/cut.mjs`, then render again. Change zooms, speeds or captions in `video/src/edit.ts` and `video/scripts/record.mjs`.
4. **Preview and tweak.** Run `npm run dev` in `video/` to open Remotion Studio, where every scene can be scrubbed and edited.
5. **Check.** Watch it once with sound and once on mute. Confirm the file is under 40 MB.
